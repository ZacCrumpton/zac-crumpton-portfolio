# Zac Crumpton — Portfolio

Personal portfolio website for **Zac Crumpton**, a Designer + Creative Developer based in Nashville, Tennessee.

This site is being designed and developed from scratch as both a professional portfolio and a demonstration of front-end development, interaction design, visual design, and creative direction.

## Project Overview

Rather than using a conventional portfolio layout, the site is built around the concept of an **interactive creative archive / project index**.

The portfolio will showcase work across:

* Web design and development
* Graphic and visual design
* Photography
* Videography and editing
* Creative direction

The goal is to create an experience that feels distinctive and highly designed while remaining intuitive, accessible, responsive, and performant.

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.

## Design Direction

The visual system draws inspiration from:

* Editorial design
* Brutalist web design
* Creative studio websites
* Contact sheets
* Record packaging
* Production files
* Archival systems
* Technical indexes and catalogs

The guiding principle for the project is:

> **Unique does not mean difficult to use.**

Experimental interactions should enhance the work without compromising usability.
